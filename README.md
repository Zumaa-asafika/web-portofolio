# Portofolio ZUM'A ASAFIKA

Website portofolio pribadi untuk menampilkan profil, keterampilan, proyek latihan, pencapaian, CV, serta informasi kontak ZUM'A ASAFIKA sebagai mahasiswa Pendidikan Teknologi Informasi.

**Demo:** https://zumaa-asafika.github.io/web-portofolio/

## Fitur

- Navigasi responsif dengan menu khusus perangkat mobile
- Tampilan hero dan kartu editor kode bergaya modern
- Bagian proyek, kemampuan, profil, pencapaian, dan kontak
- Animasi elemen saat masuk ke area layar
- Indikator progres saat menggulir halaman
- Efek cahaya dan interaksi kartu sesuai posisi kursor
- Skill terminal dengan indikator kemampuan
- Formulir kontak yang membuka aplikasi email pengguna
- Tombol menyalin alamat email dan mengunduh CV
- Tombol kembali ke bagian atas
- Tata letak responsif untuk desktop, tablet, dan mobile

## Teknologi

- HTML5
- CSS3
- JavaScript native
- Google Fonts (Poppins)
- Font Awesome

Proyek ini tidak memerlukan framework, bundler, atau proses build.

## Menjalankan Lokal

### Opsi 1: Membuka langsung

Buka file `index.html` melalui browser.

### Opsi 2: Menggunakan server lokal

Dari folder proyek, jalankan salah satu perintah berikut:

```powershell
python -m http.server 8000
```

Kemudian buka `http://localhost:8000` pada browser.

Atau, jika menggunakan Node.js dan `serve` telah terpasang:

```bash
npx serve .
```

## Deployment GitHub Pages

1. Push seluruh file proyek ke repository GitHub.
2. Buka repository, lalu pilih **Settings > Pages**.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch utama dan folder root (`/(root)`), lalu klik **Save**.
5. Tunggu proses deployment selesai, kemudian akses URL GitHub Pages proyek.

Untuk mengubah informasi pribadi, tautan sosial, email, atau sertifikat, edit bagian yang bersangkutan langsung pada `index.html` dan pastikan nama berkas aset tetap sesuai dengan struktur folder.
